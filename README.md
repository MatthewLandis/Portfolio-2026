## What's on it

- **Projects:** a browsable showcase of my apps, [Expire](https://github.com/MatthewLandis/Expire), [Yu-Gi-Oh! Card Maker](https://github.com/MatthewLandis/CardMaker) and [Notebook](https://github.com/MatthewLandis/Notebook-Frontend), each with a screenshot, description, tech stack and links to the live site and code.
- **About:** a short intro, my core skills, and a résumé download.
- **Contact:** email, LinkedIn and GitHub links.
- Works on desktop, tablet and phone.

## Built with

HTML, CSS and plain JavaScript, with no framework or build step. It's hosted on **Firebase Hosting**, and every push to `main` deploys automatically through a **GitHub Actions** workflow.

## Running it locally

Open `src/index.html` in a browser, or serve the `src` folder with any static server:

```bash
npx serve src
```
